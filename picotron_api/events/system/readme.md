# System Events

## Overview

Events that can be sent to the window manager (pid 3); most of these are restricted to unsandboxed processes.

Processes in Picotron each have an entirely separate Lua state, but are able to communicate with each other via messages, which are strings generated by using [pod()](/picotron_api/functions/pod/main.md) on a message.

Most programs do not need to deal with messages directly; for example [mouse()](/picotron_api/functions/mouse/main.md) can be used to retrieve the state of the mouse (instead of subscribing to mouse event messages).

The following list is provided for low-level programming, and for some functionality that has not *yet* have a corresponding interface in the API.

These events can be sent to the wm with:

```lua
send_message(3, {event="event_name", foo=bar, ...})
```

# open(location)

## Overview

Opens the file location `location` using the [`open` utility](/system/details/util/open/main.md).

## Arguments

### `location`: string

The filepath to open; relative to the present working directory

## Examples

Sourced from the [Picotron Manual](https://www.lexaloffle.com/dl/docs/picotron_manual.html)

Open a `readme.txt` stored in the working directory
```lua
open("readme.txt")
```

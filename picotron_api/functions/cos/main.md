# cos(a)

## Overview

`cos` gives the cosine of value `a` where 1 is one full turn.

## Arguments

### `a`: float or int

The value you want to get the cosine of.

## Examples

Print a string that wriggles up and down by offsetting it by the cosine of time().

```lua
	print("\^o1ffp𝘳𝘦𝘴𝘴 ❎ t𝘰 p𝘭𝘢𝘺",30,60+cos(time()),7)
```
